# Arctic Analysis

**UTRA Hacks 2026**

Arctic Analytics is a robotics and data analytics project built at **UTRA Hacks 2026**. The system focuses on a robot that navigates a winter biathlon-style track while collecting sensor data to generate AI-driven feedback for future performance improvements.

---

## 🧠 Project Overview

Our robot collects real-time sensor data while navigating the track, including:

* Motor speed (RPM)
* Distance measurements (ultrasonic sensors)
* Line-following data
* Color detection data

This data is stored and analyzed to extract insights about the robot’s performance. 

---

## 🤖 Hardware & Firmware

The robot is powered by Arduino-based firmware and includes:

* Ultrasonic distance sensors
* IR sensors for line following
* Color sensors for track detection
* Motor controllers for movement and steering

### Firmware Files

* `motor.ino`, `motors.ino` – Motor control logic
* `UltrasonicSensor.ino`, `ultrasonic.ino` – Distance sensing
* `LineFollow.ino` – Line-following behavior
* `ColorSensor.ino` – Color detection
* `Arm.ino` – Actuator/arm control
* `Final` – Main integrated sketch
